# Codex custom agents

These nine TOML files are generated by `scripts/build-skills` from the pinned upstream
`workforce/agents/*/AGENT.md` handbooks and the two code-evaluator bundled advisors. Both
installers copy them into `.codex/agents/` at the chosen scope and record what they wrote in
`installed-agents.txt` so uninstall can remove exactly those files.

Codex custom-agent files accept `name`, `description`, `developer_instructions`,
`model_reasoning_effort` and some feature/skill disables. They have **no** per-agent
`tools:` allowlist and no `disallowedTools:` enforcement; the upstream grants are retained
only as instructions, and every generated file says so in its first paragraph.

Model IDs are deliberately omitted. The upstream pins name Claude models that Codex cannot
run; each agent inherits the session model until the user assigns a supported Codex model in
the TOML. Effort is copied from upstream where it was stated, because Codex accepts
`model_reasoning_effort` independently of the model.
