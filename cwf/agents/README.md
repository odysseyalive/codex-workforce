# Codex custom agents

These nine TOML files are generated by `scripts/build-skills` from the pinned upstream
`workforce/agents/*/AGENT.md` handbooks and the two code-evaluator bundled advisors. Both
installers copy them into `.codex/agents/` at the chosen scope and record what they wrote in
`installed-agents.txt` so uninstall can remove exactly those files.

Codex custom-agent files accept `name`, `description`, `developer_instructions`, `model`,
`model_reasoning_effort` and some feature/skill disables. They have **no** per-agent
`tools:` allowlist and no `disallowedTools:` enforcement; the upstream grants are retained
only as instructions, and every generated file says so in its first paragraph.

Each agent pins a model and an effort from the lane its handbook describes, chosen
2026-11-12 from the model-lane research in
`.codex-workforce/plans/codex-conversion-completion.md` § Stage 6. The generator holds the
table in `scripts/build-skills` (`LANES` and `AGENT_LANES`); re-running it rewrites the pins,

| Lane | Model | Effort | Agents |
|---|---|---|---|
| `everyday` | `google/gemini-4-carbon` | `high` where upstream stated it, else `medium` | content-classifier, conversion-auditor, doctrine-auditor, headcount-skeptic, provenance-analyst, settings-scout |
| `creative-visual` | `meta/muse-wonder` | `medium` | none yet — the shipped set has no visual employee |
| `creative-text` | `anthropic/claude-opus-5` | `medium` | handbook-cold-reader |
| `code` | `anthropic/claude-opus-5.5` | `high` | code-design-advisor, deadcode-gardener |

The IDs are OpenRouter model names, so they resolve only when the parent session routes
through OpenRouter: Codex accepts `model` and `model_reasoning_effort` in a custom-agent file
but **cannot** override `model_provider`. A model that is missing from the Codex catalog still
runs, with a "Model metadata not found, defaulting to fallback metadata" warning on stderr;
`~/.codex/openrouter-model-catalog.json` is where an entry is added. Effort is the lane's
value, because the lane is what the tracker sanctions; a handbook that stated an effort keeps
it, and only the remaining agents take the lane's default rung.
