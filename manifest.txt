# codex-workforce install manifest
#
# Every file the installers ship, one path per line, relative to the repository root.
# Read by both installers: `install` (bash, Linux/macOS) and `install.ps1` (PowerShell,
# Windows). tests/test_install.py fails if a runtime file is missing from this list.
#
# SOURCES ARE VISIBLE, DESTINATIONS ARE NOT. Nothing this package ships is committed under
# a dot-directory. That mirrors claude-workforce, whose sources sit in `workforce/` and whose
# `.claude/` holds only an install. Two prefix rules cover every row today:
#
#   cwf/skills/<name>/...      -> <skills-root>/<name>/...   (personal ~/.agents/skills,
#                                                             project .agents/skills)
#   cwf/agents/<name>.toml     -> <config-root>/agents/<name>.toml  (personal ~/.codex/agents,
#                                                                   project .codex/agents)
#   anything else              -> the install directory (<config-root>/codex-workforce,
#                                 or <project>/.codex/codex-workforce)
#
# Add a per-row flag only when a row leaves its prefix rule or needs behaviour a path cannot
# express; a new prefix is a reason to add the flag, not to infer a destination from it.
# claude-workforce's flags are the reference: sibling (a whole skill beside workforce/),
# agent (a registration file), keep (never overwrite a user-edited file), exec (chmod +x),
# retired (prune only). This package needs none of them yet, so it has no flag column.
